Tsursport iOS · 使用须知

  1. 工作原理：电脑通过 Apple 开发者调试通道（pymobiledevice3 + DTX）注入系统级定位，不越狱、不签名、不在手机装 App，且 App 侧无 Android 的 isMock 标记。
  2. 必备前置：Windows 需安装 Apple 驱动服务（Apple Mobile Device Support 或微软商店「Apple 设备」/ iTunes）；iPhone 需开启「设置 → 隐私与安全性 → 开发者模式」并插线点击「信任此电脑」。
  3. 必须保持连接：模拟期间不可拔线或断网（否则定位立即回弹真实位置）；若锁屏后休眠断连，建议在「设置 → 显示与亮度 → 自动锁定」暂时设为更长时间或开启引导式访问。
  4. 配速与里程：常规校园跑有效配速约 3'30"–10'00"/km（即 1.7–4.7 m/s），默认 2.6 m/s (6'25"/km)；到达目标里程后系统会保持锁定终点，请在支付宝完成结算/打卡后再点「恢复真实定位」。
  5. 防止支付宝覆盖定位：高德/支付宝 SDK 会结合附近 Wi-Fi 反查定位，跑前建议关闭手机 Wi-Fi（用 4G/5G 移动数据），并强杀支付宝后重新打开再开始模拟。
  6. 重要边界：iOS 步频/运动传感器数据无法通过调试通道伪造，人仍需真实摇晃/走动产生步数；静止 0 步频或出电子围栏仍可能被风控复核判定异常。
